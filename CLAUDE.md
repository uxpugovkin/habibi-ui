# Habibi UI — instructions for AI assistants

Read `README.md` → "The rules of this design system" before changing anything.

**Rule 7 is a hard stop:** never edit, add or delete anything under `src/lib` (the shared design
system) without asking first and getting an explicit "yes" in the conversation. Say what would
change and why, then wait. Prototypes and docs pages under `src/routes` may be changed freely.
